## Description ##

This application serves recreational scuba divers and dive shops by providing a safety-focused dive planning and air consumption estimation system. Scuba diving safety relies heavily on predicting how much breathing gas a diver will consume based on water pressure, duration, and personal physiological traits. However, beginner divers often lack historical air consumption logs, making pre-dive planning uncertain and potentially dangerous. This system solves this issue by dynamically estimating a baseline Surface Air Consumption (SAC) rate using the diver's physical attributes, then incorporating dive variables such as target depth, planned duration, and dive scenario type to determine the air volume required and recommend the minimum tank size needed for a safe dive.
 
## Color ##

Main Color: Ocean Navy Blue (#003366)
Secondary Color: Light Aqua Blue (#66B2CC)
 
 
## Required Fields ##

diveId int Unique identifier generated by the application <br/>
diverName String Name of the diver <br/>
heightCm double Diver's height in centimeters <br/>
weightKg double Diver's weight in kilograms <br/>
gender String MALE or FEMALE <br/>
ageGroup String AGE_10S, AGE_20S, AGE_30S, AGE_40S, AGE_50S_PLUS <br/>
targetDepthMeters double Planned maximum dive depth in meters <br/>
plannedTimeMinutes double Planned bottom time in minutes <br/>
diveScenario String DRIFT (1.0), CAVE_WRECK (1.25), COUNTER_CURRENT (1.5) <br/>
 
## Calculation ##

The calculation / processing needed when the user enters a new dive plan will be to determine the total air volume required and the recommended tank size. The baseline SAC rate is calculated from Body Surface Area using the Mosteller formula (bsa = square root of heightCm times weightKg divided by 3600), multiplied by a gender factor (9.8 for MALE, 9.0 for FEMALE) and an age multiplier (1.10 for 10s, 1.00 for 20s, 0.98 for 30s, 1.05 for 40s, 1.15 for 50s+). The effective SAC is the baseline SAC multiplied by the dive scenario multiplier, and the total air needed in liters is the effective SAC multiplied by the atmospheres absolute (targetDepthMeters divided by 10 plus 1) and the planned time in minutes. The recommended tank size in liters is the total air needed divided by 150, assuming a standard 200 Bar tank with a 50 Bar safety reserve.
